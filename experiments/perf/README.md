# 動作の重さの測定

出題画面を、スマホ相当（幅390px・3倍密度・CPU 4倍遅く）のヘッドレスChromeで測る。結果と改善案は [docs/research/軽量化の調査.md](../../docs/research/軽量化の調査.md)。

## 実行
`web/` で開発サーバー（`npm run dev`）を起動してから:

```
node measure.mjs [URL]    # 既定 http://localhost:5173/q/1 （打牌かリーチの問題を選ぶ）
```

- Node 24とChromeが要る。Chromeの場所は `CHROME_PATH` で変えられる。
- 出力: 出題中に5秒待つ間のメインスレッドの使用時間（タップを促す光あり／なし）と、手牌をタップしてから次のフレームまでの時間。
- 問題を割り当てて回答前の状態を作るため、本番のURLには向けない。
