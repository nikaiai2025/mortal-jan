# 牌譜レビュー機能の追加に関する調査（mortal-jan）

2026-09-30時点。法的助言ではなく、一次情報に基づく調査。
確からしさ: 確実＝条文・当事者の表明・実物で直接確認できる／有力＝確認した事実から強く推定できる／不明＝確認できない。
AGPLの伝播範囲と「Mortal」の名称は `ライセンス・名称調査.md` を前提とし、ここでは繰り返さない。

## 結論の要約

1. **同種のサービスは、無料のものや各プラットフォーム公式のものがすでに揃っている。** Mortal作者の公式レビュー（mjai.ekyu.moe）は、天鳳・雀魂・麻雀一番街・任意の牌譜に無料で対応している。雀魂と一番街はゲーム内に公式の解析機能を持つ。mortal-janが牌譜レビューを追加しても、利用者にとっての上積みは小さい。【確実】
2. **最も重いリスクは2つ。**
   - 雀魂の牌譜をURLから自動取得すること。雀魂のアカウントで非公式APIにログインする方式しかなく、雀魂規約（不正な方法での取得、リバースエンジニアリング、アカウントを第三者に利用させる行為）と衝突する。先行事例でも取得元が遮断されている。
   - リアルタイム補助に転用されること。任意の局面を即座に評価できる入口（部分牌譜やAPI）を作ると、対局中の不正に使える。これはMortal作者が重みを公開しない理由そのものに当たる。

   【規約・表明は確実／本件への当てはめは有力】
3. **天鳳の牌譜の扱いは、規約の読み方次第で結論が変わる。**
   - 天鳳での対局を振り返るレビューは、天鳳の規約の趣旨（天鳳での対戦を公正に楽しむ）に沿うと読める。ただし明示の許可はない。
   - サーバーが代理で取得した牌譜を再表示させたりダウンロードさせたりすると、「不特定多数が牌譜をダウンロードするサービス」の禁止に近づく。
   - 天鳳の牌譜で学習した重みで雀魂の牌譜を評価することは、「天鳳と競合する製品への応用」の禁止に触れうる。

   【条文は確実／当てはめは不明】
4. **AGPL第13条は障害にならない。** リポジトリはすでに公開しているので、稼働中の版のソース（推論サーバーとコンテナ定義を含む）を画面から案内すれば足りる。【有力】
5. **今の「事前生成の何切る問題」との差。** 現行は、実行時にMortalを動かさず、第三者の牌譜と名前を扱わず、任意の局面を評価できない。牌譜レビューを加えると、次の5点が新たに生じる。
   - AGPL第13条の義務
   - 牌譜に関する各プラットフォームの規約
   - 個人情報
   - 不正への転用
   - 費用（Workers無料プランの範囲を出る）

   【有力】

## 不明点

- 天鳳の運営が、NAGA以外の第三者による天鳳牌譜のレビュー（代理での取得を含む）を認めるか。また、天鳳の牌譜で学習した第三者の重みを使う者に、天鳳の条件が及ぶか。
- 雀魂の運営が、対局後に牌譜を取り出すツール（拡張機能・ユーザースクリプト）を規約違反とみなすか。明示されているのは「進行中の対局を有利にする外部ツール」だけ。
- Mortal作者が、第三者の重みと第三者のレビューサービスを現在どう見ているか。2022年の表明以降、更新はない。
- 牌譜の著作物性（確定した判例がない）。
- クラウド上での推論時間とコールドスタート、ブラウザ内推論が実現できるか。いずれも手元の実測から推定しただけ。

## 推奨

**牌譜レビューは提供せず、公式レビュー（mjai.ekyu.moe）へのリンクを置く。** 結論1と5のとおり、追加の価値は小さく、リスクと費用が新たに生じる。

提供する場合に最低限必要な条件は次のとおり。

1. 入力は、天鳳形式（tenhou.net/6形式のJSON、または天鳳のURL）の終局済みの半荘に限る。雀魂の自動取得はしない。
2. 局面単位の評価や公開APIは作らない。自サイトからの利用だけを受け付け、Turnstile、1人あたりの1日の上限、同時実行の上限を設ける。
3. 牌譜そのものを保存・再配布しない。他家の名前は表示しない。結果は短期間で削除し、共有は本人が明示的に操作したときだけにする。
4. 「非公式・AI評価（mortal-298k）」と表示し、公式レビューへのリンクと、稼働中の版のソースへのリンク（AGPL第13条）を置く。
5. 公開する前に天鳳の運営へ照会し、できればMortal作者にも連絡する。

構成は、既存のWorker（受付と制限）から Cloudflare Containers（standard-1、PyTorchとmortal-298k、同時実行1、待機後にスリープ）を呼ぶ形にする。費用は Workers Paid の月5ドルに従量課金が加わる。

次のいずれかに当てはまる場合は、提供しない方がよい。

- 雀魂のURLからの自動取得が必須の要件になる場合
- 任意の局面を即座に評価する機能（部分的な牌譜の受け付けやAPI）を出したい場合
- 天鳳の運営から否定的な回答があった場合
- 月5ドルと従量の費用、または不正や苦情への対応を負担できない場合
