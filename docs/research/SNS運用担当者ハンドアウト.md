# もーたる何切る教室 SNS運用担当者ハンドアウト

Xを想定した初期運用案。2026年10月5日。

## 目的と担当範囲

麻雀のルールを知っていて、何切る判断を鍛えたい人にサイトを届けます。麻雀の話を楽しみながら、問題を解くきっかけを作ってください。

担当するのは、投稿の企画・作成、麻雀関連のフォロー、会話への返信、利用者の声の記録、運営者への報告です。親しみやすい運営担当者として話し、段位や実力を誇張しません。担当者が開発者本人でなければ、開発の話は開発者から聞いたこととして紹介してください。

サイトは登録不要・無料の何切る練習サービスです。1万問の打牌・リーチ・鳴きを解き、回答後に自分の判断とAI評価を比べられます。採点には第三者配布のmortal-298kを使っています。Mortalの公式サービスや公式モデルとは表現せず、AI評価を唯一の正解や実戦での上達の証明にしません。[サイトと採点の説明](https://mortal-jan.shika.workers.dev/about)。

## 投稿と交流

| 種類 | 内容 | 作り方 |
|---|---|---|
| 何切る | 盤面を見せて「あなたなら何を切る？」と問いかける | サイトの共有画像を使い、画像と同じ問題へのリンクを付ける。出題では採点結果を隠し、評価を紹介する投稿には結果を含むと明記する |
| 日常 | 麻雀の練習、対局を見た感想、制作中の小さな気づき | 担当者自身の体験か、本人が公開してよいと確認した話を使う。リンクを付けない投稿も作り、話題がなければ休む |
| 開発の苦労話 | 困ったこと、試したこと、今どうなったか | 開発者の話や公開記録で事実を確かめ、利用者にどう関係するかを書く。未実装の機能を使えるとは言わない |
| 使い方と改善 | 今日の10問、見直し方、公開済みの変更 | できることを画面で示す。機能の羅列より、練習のどの場面で使えるかを伝える |

フォロー先は、何切るを投稿する人、麻雀の練習を続ける人、麻雀ツールの作者や学習コミュニティから選びます。実際の投稿を読んで、今後も読みたい相手をフォローしてください。人数のノルマ、大量のフォローと解除、フォロー返しの要求は設けません。

返信は相手の話題に沿って、自分の考えや具体的な質問を返します。他人の投稿に無関係な宣伝リンクを付けず、同じ文面を配りません。画像は自サイトのものを使い、他人の投稿や画像を紹介するときは元の投稿を共有してください。

## 開始と担当者の判断

1. 運営者が使用アカウント、担当者の名義、人間とAIの役割、公開してよい範囲を指定します。プロフィールと固定投稿に、誰が運営し、どんな人向けのサイトか、サイトへのリンクを載せます。人間へ権限を渡す場合はX Delegateを使い、パスワードを共有しません。[権限の渡し方](https://help.x.com/en/managing-your-account/how-to-use-the-delegate-feature)。
2. サイトへの誘導は、[最初の試行と投稿文案](集客の最初の試行.md)の計画に沿って始めます。同じ文案を連投せず、各投稿に用意した計測付きリンクを使います。その間の日常投稿や会話は、事実と反応に応じて行ってください。投稿数を埋めるための創作はしません。
3. 作業日には通知と麻雀関連の投稿を確認し、返信と次の素材を準備します。最初は1日15分程度を作業時間の目安にし、週1回結果を報告してください。この頻度は試行のための提案で、結果と負担を見て調整します。

指定された公開範囲内の日常・何切る・確認済みの開発話・通常の返信は、担当者の判断で進めます。未確認の事実、公開前の情報、費用や提携の約束、個人情報を含む内容は運営者へ確認してください。誤った投稿は速やかに訂正し、不具合報告は問題番号・端末・起きたことを記録して引き継ぎます。

AI評価への疑問には、問題番号と選んだ手を確認します。分からない理由を作らず、必要なら開発者へ引き継いでください。成績の復旧相談では、復活の呪文を公開の返信に書かせません。

AI担当は実体験を創作せず、運営との関係をプロフィールで明らかにします。公開操作の自動化はXのAPIと規約に沿って別途設計し、ブラウザ操作で自動運用しません。AIによる自動返信にはXの事前の書面承認が必要です。[自動化のルール](https://help.x.com/en/rules-and-policies/x-automation)。

## 記録と改善

主に見る成果は、サイトで新しく1問解いた人の数です。訪問者数と24時間以内の初回回答率で入口を、7日以内の再利用率で継続を確認します。フォロワー数・表示数・いいね数は、届き方を知る補助情報として扱ってください。

投稿ごとに、公開日時・投稿URL・内容の種類・計測リンクの投稿名を1つの記録に残します。週報は次の4項目で十分です。

- 公開した投稿と、確認できる表示数・反応。
- 流入元・投稿別の訪問者数と初回回答者数。割合は分子・分母の人数も示す。
- 利用者の疑問・不具合・要望。個人情報は載せない。
- 次に変えることを1つと、その根拠。

集計は[計測の定義と手順](../../tools/acquisition/README.md)を使い、担当者に管理権限がなければ運営者が集計結果を渡します。観測待ちは0%として扱わず、少人数の反応や1件の投稿だけで優劣を決めません。結果に応じた改善は、最初の試行の「結果から次に変えること」に沿って進めてください。

重複投稿・無関係な宣伝返信・体験や実績の偽装を避ける基準は、[XのAuthenticity方針](https://help.x.com/en/rules-and-policies/authenticity)に沿っています。媒体や自動化の方式を変える場合は、その時点の公式規約を確認してください。
