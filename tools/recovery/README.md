# 運営による成績の復旧

申請者の説明を信頼し、名前から該当する成績を選ぶ運用。本人確認機能は持たない。

1. リポジトリ直下で `node tools/recovery/recover-player.mjs --remote` を実行する。Node.js 24、`web/` のnpm依存、D1へのCloudflare権限、復活の呪文機能の本番配信とマイグレーション0005の適用が必要。ローカルで試す場合は `--local` にする。
2. 名前（部分一致）か公開IDで検索し、候補の番号を選ぶ。同名の場合は公開ID、登録日時、回答数、最終回答日時で区別する。無名の人は `名無し#公開ID` でも検索できる。
3. 対象を確認して `y` を入力する。新しい呪文が表示され、Windowsではクリップボードにコピーされる。発行済みの人を選ぶと旧呪文は無効になる。
4. 呪文を申請者に渡し、サイトの「成績を復旧する」から入力してもらう。入力に成功すると旧端末の認証トークンは無効になる。

変更するのは、選んだ利用者の復旧用ハッシュだけ。回答・成績・名前・通常の認証トークンは発行時には変更しない。呪文をファイルや操作ログへ保存しない。書き込み結果を受け取れなかった場合は、検索からやり直して再発行する。

認証はWranglerに任せる。`wrangler login` の保存済みログイン、または環境変数 `CLOUDFLARE_API_TOKEN` を使う。ソースは公開するが、認証情報とDBデータは含めず、ツール自体もWeb配信には含めない。
